# 08. MVCC, 잠금, 커넥션 풀

두 개의 PostgreSQL 세션을 열어 같은 사용자 행을 갱신한다.

1. 세션 A가 트랜잭션을 시작하고 사용자 행을 갱신한 채 커밋하지 않는다.
2. 세션 B가 같은 행을 갱신해 대기하도록 만든다.
3. 세션 C에서 `pg_stat_activity`와 `pg_locks`로 대기 원인을 찾는다.
4. 세션 B에 `lock_timeout`을 설정해 무제한 대기를 막는다.
5. 롤백 후 API 부하에서 풀 크기 5와 30을 비교한다.

완료 조건은 대기 세션 PID, 대기 이벤트, 블로커 PID를 쿼리로 연결해 설명하는 것이다.
