# 01. 요구사항을 SQL로 변환

제품 담당자가 다음 목록을 요청했다.

> 2010년에 작성된 PostgreSQL 질문 중 점수가 5점 이상인 글 20개를 점수 높은 순으로 보여 주세요. 점수가 같으면 최근 글을 먼저 보여 주세요.

반환 열은 `id`, `title`, `score`, `creationdate`, `owneruserid`다.

완료 조건:

- 질문만 포함한다.
- 2010년의 양쪽 날짜 경계를 정확히 처리한다.
- PostgreSQL 태그 전체 토큰을 찾는다.
- 동일한 입력에서 정렬 결과가 항상 같다.
