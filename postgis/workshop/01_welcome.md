# 1. 환영합니다 (Welcome)

> 공식 원문: [<https://postgis.net/workshops/postgis-intro/welcome.html>](https://postgis.net/workshops/postgis-intro/welcome.html)\
> 공식 소스의 본문·표·SQL·이미지를 현재 페이지 순서대로 반영했습니다.

## 워크숍 표기 규칙 (Workshop Conventions)

이 워크숍은 내용을 직관적으로 따라갈 수 있도록 몇 가지 서식 및 표기 규칙을 사용합니다. 이 절에서는 각 장의 구성과 문서에서 사용하는 표기법을 간단히 소개합니다.

### 안내 사항 (Directions)

워크숍 참석자 및 학습자가 직접 수행해야 하는 실습 지침은 **굵은 글꼴(Bold)**로 표시됩니다.

예:

> 계속 진행하려면 **Next**를 클릭하세요.

### 코드 블록 (Code)

SQL 쿼리 및 셸 명령어 예제는 별도의 코드 블록 상자에 표시됩니다.

```sql
SELECT postgis_full_version();
```

이러한 예제 코드는 pgAdmin의 쿼리 도구 창이나 `psql` 명령줄 인터페이스에 그대로 복사하여 실행할 수 있습니다.

### 참고 노트 (Notes)

노트 상자는 학습 주제를 이해하는 데 도움이 되는 유용한 배경지식이나 부가 정보를 제공할 때 사용됩니다.

> [!NOTE]
> 하루 한 알의 사과를 먹지 않으면 의사를 만나야 할 수도 있습니다. (서양 속담 인용 예시)

### 함수 표기 (Functions)

본문에서 SQL 함수명을 정의하거나 설명할 때는 `코드 글꼴` 또는 **굵은 글꼴**로 표시됩니다.

예:

> `ST_Touches(geometry A, geometry B)`는 두 지오메트리의 경계가 서로 접촉하고 내부는 겹치지 않을 때 `TRUE`를 반환합니다.

### 파일, 테이블 및 컬럼 이름

파일명, 디렉터리 경로, 테이블명, 컬럼(열) 이름은 고정폭 코드 글꼴(`fixed-width`)로 표시됩니다.

예:

> `nyc_streets` 테이블에서 `name` 컬럼을 조회합니다.

### 메뉴 및 UI 요소

메뉴/서브메뉴 경로, 입력 필드, 체크박스 등 화면의 UI 컨트롤 요소는 *기울임꼴(Italic)*로 표시됩니다.

예:

> *File > New* 메뉴를 클릭한 뒤, *OK* 체크박스를 선택하세요.

### 학습 진행 흐름 (Workflow)

각 장은 앞서 다룬 개념을 이해했다는 전제하에 점진적으로 구성되며, 이전 장의 지식을 토대로 다음 단계의 고급 주제를 다룹니다.

각 절에서는 먼저 핵심 개념을 단계별로 설명하고 실무 예제를 함께 제시합니다. 각 절의 마지막에는 학습한 내용을 직접 확인해 볼 수 있는 연습 문제(Exercises)가 포함되어 있습니다. 일부 절에는 기본 실습보다 난이도가 높은 심화 도전 과제(Things to try)도 제공됩니다.
