# 28. 3차원 데이터 (3-D)

PostGIS는 2차원(X, Y)뿐만 아니라 고도/높이(Z) 및 측정값(M)을 포함하는 **3차원 및 4차원 지오메트리**를 지원합니다.

---

## 1. 3D 지오메트리 표현

- `POINT Z(0 0 10)`
- `LINESTRING Z(0 0 0, 1 1 5, 2 2 10)`
- `POLYGON Z(...)`

---

## 2. 3D 전용 공간 함수

일반 `ST_Distance`는 Z값을 무시하고 2D 평면 거리만 계산하지만, `3D` 접두사가 붙은 함수는 Z축 높낮이를 반영한 입체 공간 연산을 수행합니다:

- `ST_3DDistance(geom1, geom2)`: 3차원 유클리드 입체 거리 계산
- `ST_3DIntersects(geom1, geom2)`: 3차원 공간 상의 교차 판별
- `ST_3DLength(geom)`: 3D 경사선 실제 연장 길이 계산
- `ST_Z(geom)`: Point 객체의 Z값(고도) 추출

```sql
-- 지표면(0,0,0)과 공중(3,4,12) 사이의 3차원 직선 거리 (피타고라스 3D: sqrt(3^2 + 4^2 + 12^2) = 13)
SELECT ST_3DDistance(
  'POINT(0 0 0)'::geometry,
  'POINT(3 4 12)'::geometry
);
```

결과: `13`
